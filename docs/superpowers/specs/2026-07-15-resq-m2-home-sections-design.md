# ResQ — Milestone 2: 홈 스크롤 섹션 설계 (마스터 스펙)

> 홈 = 한 페이지 스크롤: **①마스코트 히어로 → ②할일+일정 → ③팀 미션+학회 일정 → ④논문 분석**.
> 작성일: 2026-07-15 · 전제: Foundation + Mascot Hero(slice 2/2.5) 완료.

## 전체 구조 (사용자 확정 비전)

| 스크롤 | 섹션 | 구현 slice |
|---|---|---|
| 화면 1 | 마스코트 히어로 (완료) | ✅ slice 2.5 |
| 화면 2 | **할일 목록 + 스케줄** (개인 일정 달력 한눈에) | **Slice 3 (이번)** |
| 화면 3 | **팀 미션** (1–4년차+교수님 공유 할일판) + 학회 일정 | Slice 4 |

## 플랫폼 연동 정책 (정직한 경계)

- **Google Calendar 동기화**: Google OAuth **추가 스코프** + 토큰 관리 필요 → Slice 4.5에서 별도 (운영자 GCP 설정 필요).
- **Apple/갤럭시 캘린더**: 공개 API 없음 → **ResQ가 ICS 구독 피드 발행**(Edge Function), 기기 캘린더가 구독. (Slice 4.5)
- **iPhone 미리알림/갤럭시 리마인더**: 공개 API 없음. **양방향 동기화는 웹앱에서 불가능** — 앱 내 할일 + (선택) 할일 마감일의 ICS 노출로 대체. 이 한계는 확정.
- **Gmail → 캘린더**: Gmail 스코프 + 서버측 Claude 파싱 → Slice 6 (운영자 설정 필요).
- **논문 AI 분석**: Anthropic 키는 서버측(Edge Function) 전용 → Slice 5 (운영자 키 배포 필요). PubMed 수집·목록은 키 없이 동작.

## Slice 3 범위 (이번)

- **DB** `0003_todos_events.sql`: `todos`(제목/완료/마감/xp_granted) + `events`(제목/시작/종료/종류/장소/메모) + RLS(본인 행만).
- **할일**: 추가/완료 토글/삭제. **첫 완료 시 `schedule_done` XP +8** (`xp_granted` 플래그로 재완료 파밍 방지) → 큐비 성장과 연결.
- **일정**: 월 달력 그리드(순수 로직 `monthGrid`) + 일정 추가 폼(제목/날짜/시간/종류: 수술·학회·회식·교수님·기타) + 당월 일정 목록 + 삭제. 알람/반복은 Google 연동 slice에서.
- **홈 조립**: `HomeSections`(섹션 2 + 섹션 3/4 자리표시 "곧") — App은 Hero 아래에 붙임. 네비 '캘린더' 탭 → 섹션 2로 앵커 활성화.
- 테스트: monthGrid 경계, 데이터 접근(모킹), XP 1회 지급, 컴포넌트 상호작용.

## Slice 3 명시적 제외
Google/ICS 동기화, 알람 푸시, 반복 일정, 드래그 이동, 팀 공유(→S4), 논문(→S5), 자연어 일정 입력.
