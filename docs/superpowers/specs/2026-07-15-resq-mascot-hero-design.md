# ResQ — Mascot Hero 재작업 설계 (Slice 2.5)

> 마스코트(큐비)를 홈 첫 화면의 **주인공**으로: 전공별 대표 동물 + 랜덤 변형, CSS 입체 연출, KST 낮/밤 배경.
> 작성일: 2026-07-15 · 전제: Slice 2(Mascot Zone) 코드 완료(feat/mascot, PR #2). 이 slice는 그 위 재작업.

## 1. 변경 동기 (사용자 피드백)

- 마스코트는 히어로 아래 별도 섹션이 아니라 **첫 화면 중앙의 애니메이션 캐릭터**여야 한다. 입체적으로.
- 종(species)은 유저당 완전 랜덤이 아니라 **전공별 대표 동물**(십이지 + α, 병원 친화적·귀여운 의인화)이어야 한다. 단, **랜덤 변형(variant)** 으로 "내 것"이라는 재미는 유지. (확정: 전공 동물 + 랜덤 변형)
- 배경 다양화 + **KST 시간에 따른 낮/밤 전환**.
- 입체감 구현 수위 확정: **CSS 연출** (추가 라이브러리 없음).

## 2. 전공 → 동물 매핑 (config)

`src/mascot/roster.ts`를 전공 키 기반으로 개편. 초안 매핑(십이지 + α, 전부 config — 수정 자유):

내과=강아지(dog), 정형외과=소(cow), 외과=말(horse), 마취통증의학과=카멜레온(chameleon),
소아청소년과=토끼(rabbit), 산부인과=닭(rooster), 정신건강의학과=고양이(cat),
영상의학과=원숭이(monkey), 응급의학과=호랑이(tiger), 신경과=용(dragon), 신경외과=용(dragon),
피부과=뱀(snake), 이비인후과=쥐(mouse), 안과=양(sheep), 비뇨의학과=돼지(pig),
가정의학과=곰(bear), **기타/미매핑=알파카(alpaca, 기본값)**.

- **변형(variant) 4종**: 씩씩이 / 순둥이 / 똘똘이 / 엉뚱이 — 색조(tint shift)와 성격 라벨만 다름.
  배정은 `hash(userId) % 4` — **DB 변경 없이** 유저마다 고정된 "부화 랜덤".
- 온보딩의 전공 입력: **자유 텍스트 → 셀렉트 드롭다운** (매핑 보장). 기존 프로필의 자유 텍스트 전공은
  매핑 실패 시 알파카 fallback으로 동작 (에러 없음).

## 3. 히어로 = 마스코트 무대

`Hero.tsx` 개편 + `MascotZone.tsx` **삭제(흡수)**:

- **중앙 무대**: 큰 마스코트 글리프(placeholder) — idle 부유(`float` keyframes) + 호흡 스케일 + 마우스 이동에 따른 미세 패럴랙스(transform, 최대 ±8px). 뒤에 고스트 텍스트(동물명 또는 Lv). 발밑 그림자 타원으로 접지감.
- **좌상단 정보 블록(유지, 컴팩트)**: 인사/`N년차 · 병원 전공`/D-day + 진행바.
- **하단 스탯 바(liquid-glass)**: 큐비 이름·변형 라벨 · Lv/XP바 · 기분 · 연속출석 · 단계(현재 단계 텍스트 + 좌우 화살표로 단계 프리뷰 — 기존 캐러셀 축소판).
- 네비/소셜 아이콘/로그아웃은 기존 그대로.
- 접근성: 장식 요소 `aria-hidden`, 기존 테스트 쿼리 패턴 유지(중복 텍스트 매치 회피).

## 4. 배경: KST 낮/밤 씬

- CloudFront 비디오 placeholder **완전 제거** (외부 의존 제거).
- `src/mascot/daylight.ts`: `timeOfDayKST(now)` 순수 함수 → `DAWN`(05–08) | `DAY`(08–17) | `DUSK`(17–20) | `NIGHT`(20–05). **항상 KST 기준**(`Asia/Seoul`), 사용자 기기 TZ 무관.
- 씬별 CSS 그라디언트 하늘 + 미니멀 장식(밤=별 도트, 낮=구름 블롭 — CSS만). 전공 동물 tint를 하늘에 약하게 블렌드.
- 씬 전환은 마운트 시 결정(실시간 틱 불필요 — YAGNI. 새로고침이면 충분).

## 5. 데이터 모델

- **DB 마이그레이션 없음.** species는 렌더 시 `specialty → animal` 파생, variant는 `hash(userId)` 파생.
- `profiles.mascot_species` 컬럼: 이제 미사용(향후 커스텀 오버라이드용으로 유지). `assignSpeciesIfMissing` 데이터 접근 함수와 그 upsert 호출은 **제거** (XP/streak의 `recordDailyLogin`은 그대로).
- `deriveMascotState`: 입력을 profile(전공 포함)로 유지하되 species 결정 로직을 매핑+variant로 교체.

## 6. 테스트

- 매핑: 대표 전공들 → 정확한 동물, 미매핑 → 알파카.
- variant 해시: 같은 id → 항상 같은 variant, 분포가 4종 모두 도달.
- `timeOfDayKST`: 경계(05/08/17/20 KST) + 비-KST 기기 TZ에서도 KST로 판정.
- Hero: 마스코트/스탯/기분/단계 프리뷰 렌더, D-day 유지, MascotZone 부재.
- 온보딩: 전공 셀렉트 제출 값이 매핑 키와 일치.

## 7. 명시적 제외 (이번 slice 아님)

- 홈 스크롤 섹션들(할일+일정 / 팀 미션+학회 / 논문) — 각 기능 slice에서.
- Lottie/실아트(레지스트리 교체 시점에), 진짜 3D, 실시간 시간 틱, 마스코트 커스텀(이름 변경 UI 포함).
- 캘린더/미리알림/팀보드/논문 관련 일체 (로드맵: 캘린더는 ICS 피드로 Apple/갤럭시 커버, 미리알림 양방향 동기화는 웹 한계로 제외 확정).
