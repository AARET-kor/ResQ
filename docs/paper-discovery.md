# ResQ 논문 탐색·Breakdown 운영 기준

## 목표

“최근에 검색된 논문”과 “읽을 가치가 높은 논문”을 구분한다. ResQ의 추천은
임상 의사결정이나 논문의 최종 품질 판정이 아니라, 사용자가 검토할 후보를 줄이는
탐색 보조 기능이다.

## 소스 역할

- **Europe PMC / MEDLINE**: 의학 논문의 기본 검색 소스. MEDLINE 색인, 초록 보유,
  출판 유형, 날짜, 인용 수, PMC/Open Access 여부를 사용한다.
- **OpenAlex**: 최근 인용 추세와 연관 연구 그래프를 보강한다. API 키는
  `paper-discovery` Edge Function에만 저장한다.
- **PMC·출판사·DOI·Open Access 링크**: 합법적인 원문 경로만 제공한다.
- **전공별 선별 저널·핵심 의학 저널**: 편집된 탐색 범위를 제공하되, 저널 이름만으로
  개별 논문의 신뢰성을 보증하지 않는다.

## 기본 제외 조건

- 철회 논문
- 초록이 없는 결과
- Editorial, Letter, Comment
- 기본 피드의 MEDLINE 미색인 결과
- 주제어가 제목·초록에 직접 나타나지 않는 광범위 매치

프리프린트는 향후 별도 “초기 신호” 선반에서만 제공하고, 동료평가 전 자료임을
명확히 표시한다.

## 추천 점수

추천 점수는 다음 메타데이터를 조합한 내부 휴리스틱이다.

- MEDLINE 색인 여부
- 가이드라인, 체계적 문헌고찰, RCT 등 연구 유형
- 편집된 핵심·전공 저널 목록
- 출판 후 기간을 고려한 인용 속도와 OpenAlex FWCI
- 최신성
- 합법적 Open Access 원문 가용성

이 점수는 비뚤림 위험 평가, GRADE 등급, 통계적 타당성 또는 임상 권고 강도를
대체하지 않는다. Breakdown에서 표본, 효과크기, 신뢰구간, 연구 설계와 한계를
직접 확인해야 한다.

## Breakdown 출력 기준

1. 서지정보와 연구 유형
2. 임상 질문과 PICO/PECO
3. 배경과 연구 공백
4. 연구 설계·대상·중재/노출·비교군
5. 평가변수와 통계 방법
6. 핵심 결과·효과크기·신뢰구간
7. 비뚤림 위험·한계·근거 확실성
8. 임상 적용성과 후속 질문

초록만 분석할 때 확인할 수 없는 항목은 추정하지 않고 “초록만으로 확인 불가”로
표시한다. PDF/전문 분석도 원문에 없는 수치나 참고문헌을 생성하지 않는다.

## 원문 접근 정책

Sci-Hub, Sci-Net 또는 출처·라이선스를 검증할 수 없는 사용자 업로드 논문망은
연동하지 않는다. 저작권, 개인정보, 악성 파일, 문서 변조 및 출처 추적 위험을
제품이 떠안게 되기 때문이다.

권장 순서는 DOI/출판사 → PMC/Europe PMC → Unpaywall/DOAJ → 저자 공개 원고 또는
기관 리포지터리 → 소속 기관 전자도서관·상호대차이다.

## 배포

```sh
supabase secrets set OPENALEX_API_KEY=발급받은키
supabase functions deploy paper-discovery
supabase functions deploy analyze-paper
```

키를 클라이언트의 `VITE_` 환경 변수에 넣지 않는다. OpenAlex가 일시적으로
실패하거나 배포되지 않은 경우, 기본 피드는 Europe PMC 결과만으로 계속 동작한다.

## 다음 소스 확장 순서

1. **Unpaywall**: DOI별 합법적 OA 위치를 보강한다.
2. **Crossref + Retraction Watch**: 철회·정정·우려 표명 상태를 독립적으로 교차 확인한다.
3. **KCI/KoreaMed**: 국내 학술지의 누락을 보완한다. API 이용 조건과 키를 확인한 뒤
   서버 함수로 연동한다.
4. **학회·가이드라인 공식 피드**: 전공별 학회와 guideline source를 별도 선반으로
   분리한다.

소스를 추가해도 모든 결과를 한 점수로 섞지 않는다. “근거 수준”, “화제성”,
“신착”, “국내 연구”, “OA 원문”은 서로 다른 탐색 목적이므로 선반을 분리한다.
